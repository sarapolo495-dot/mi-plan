# Mi plan · Nutrición y fuerza

App web instalable (PWA) para llevar el plan de comidas y el entrenamiento de fuerza.

- Datos y usuarios: Supabase
- Productos: base compartida + Open Food Facts + lector de etiquetas en el móvil (tesseract.js)
- Publicada con GitHub Pages

Para publicar cambios, sube los archivos y cambia `VERSION` en `sw.js`.
